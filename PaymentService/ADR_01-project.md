### <a name="_3bfxc9a45514"></a>**Функциональные требования**


|**№**|**Действующие лица или системы**|**Use Case**|**Описание**|
| :-: | :- | :- | :- |
| F1 | Плательщик |[Проведение платежа](../PaymentService/UseCases/use-case-payment.md)| Проведение платежа плательщиком|
| F2 | FraudCheck Service |[Провека платежа](../PaymentService/UseCases/use-case-antifrod-check.md)| Проверка законности платежа |
| F3 | Payment Service | Отмена платежа по инициативе клиента |
| F4 | Payment Service | Отмена платежа после обнаружения мошеннических действий (постфактум, по жалобе плательщика) |
| F5 | Payment Service | Хранить текущее состояние процесса |
| F6 | Payment Service | Обеспечивать корректное восстановление после ошибок |
| F7 | Payment Service | Хранить состояния с ожиданием ответа от сервисов проверок |
| F8 | FraudCheck Service | Все проверки с обращениями к внешним API должны выполняться с учётом тайм-аутов, retry-механизмов, идемпотентности и кеширования результатов|
| F9 | Payment Service | Нельзя допустить ситуации, когда деньги зависают между системами |
| F10 | Payment Service | Стоимость ошибки при проведении транзакции значительно выше, чем потенциальная потеря от её отклонения |
| F11 | Payment Service | Операции возврата должны выполняться автоматически, не привлекая службу поддержки в ручном режиме |

| :-: | :- |
