# Интеграционные тесты #


|**Название функции**|**Назначение**|**Что проверяется**|**Способ реализаци**|**Действие при нарушении**|
| :-: | :- | :- | :- | :- |
| SagaDataConsistency | Проверять консистентность данных между микросервисами | Соответствие данных о состоянии платежа в DB PaymentService, FraudCheckService и NotificationService | Периодическая проверка превышения допустимого отставания состояний | Нотификация тех.поддержке |
| FrozenProcessCheck | Выявлять «зависшие» процессы | Выполнение процессов за заданное время | Поиск SQL запросами процессов не достигших конечных стадий за преемлемое время | Нотификация тех.поддержке |
| SagaCompensationsControl | Обеспечивать целостность Saga-транзакций | Контроль сработки и успешности Saga компенсаций | Периодический поиск процессов в состояниях компенсаций | Нотификация тех.поддержке, retry компенсации |
| PaymentTimeoutControl | Контролировать таймауты бизнес-процессов | Платежи не длятся дольше заданного времени |Периодическая проверка превышения максимального времени выполнения | Нотификация тех.поддержке, отмена, компенсация |
