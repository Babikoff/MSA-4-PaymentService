# Шаги Saga #

|**Транзакция**|**Описание**|**Тип**|**Компенсация**|
| :-: | :- | :- | :- |
| CREATE_PAYMENT | Старт workflow платежа | Необратимая | - |
| HOLD_FUNDS | Резервирование средств | Компенсируемая | RELEASE_FUNDS |
| RELEASE_FUNDS | Отмена резервирования средств | Необратимая | - |
| CANCEL_HOLD | Отмена текущего процесса платежа по инициативе плательщика (переход к RELEASE_FUNDS) | Необратимая | - |
| ANTIFRAUD_AUTOCHECK | Автоматическая проверка легальности операции | Повторяемая | - |
| AWAITING_MANUAL_CHECK | Ожидание решения оператора в течение установленного времени (переход к ANTIFRAUD_MANUAL_CHECK или ANTIFRAUD_TIMEOUT) | Повторяемая | - |
| ANTIFRAUD_MANUAL_CHECK | Проверка легальности оператором | Повторяемая | - |
| ANTIFRAUD_TIMEOUT | Принятие решения по истечении cut-off-time (по умолчанию операция разрешена) | Повторяемая | - |
| TRANSFER_FUNDS | Перевод денег контрагенту | Компенсируемая | RETURN_FUNDS |
| RETURN_FUNDS | Возврат денег от контрагента | Повторяемая | - |
| SEND_NOTIFICATION_TO_USER | Отправка уведомления плательщику об изменении статуса операции | Повторяемая | - |
| SEND_NOTIFICATION_TO_SECURITY | Отправка уведомления службе безопасности | Повторяемая | - |
| COMPLETE_PAYMENT | Фиксация итогового состояния процесса | Необратимая | - |
| CANCEL_PAYMENT | Отмена законченного процесса платежа по инициативе плательщика (переход к RETURN_FUNDS) | Повторяемая | - |
| FINISH_PAYMENT_PROCESS | Перевод процесса в конечное состояние после компенсации (из FUNDS_RELEASED, FUNDS_RETURNED) | Необратимая | - |
